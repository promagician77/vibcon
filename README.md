# VibCon Phase 1 Notes

Single static HTML file. No build step, no dependencies.

## Deploy

```bash
cd vercel-demo
vercel --prod
```

Then paste the deployed URL into `[DEMO_LINK]` in the proposal.

## Local preview

```bash
npm run dev    # http://localhost:4321
```

## Notes

`vercel.json` and a `<meta name="robots">` both set noindex. The page discusses a
named client's system. All of it is public, but a crawlable page cataloguing their
faults is not something they would thank you for.

No fee figures appear anywhere on the page. Hours only, so a rate change never
forces a republish.

Generated by `_engine/tools/mkstandalone.py` from `../demo.html`. Re-run it after
editing the source; do not hand-edit `index.html`.
